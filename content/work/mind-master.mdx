## The problem

I wanted a small product that shows how I build a web app end to end: quick to load on a cheap phone, usable offline, and tested properly, not just clicked through once.

## What I built

Five quick games (Memory Numbers, Number Sequence, Pattern Memory, Quick Reaction and Find Different), each with three lives a run, a best score that saves on every point, and a high score screen with recent runs.

- Plain TypeScript on Vite, no framework and no runtime dependencies. The production build is about 14 KB of JavaScript.
- Installs to the home screen and keeps working offline through a service worker, with a safe update path when a new version ships.
- 28 unit tests pin each game's rules and difficulty curve, and 16 Playwright tests play the games on a phone profile. CI runs them on every change.

The code is public at [github.com/Danielsx321/mind-master](https://github.com/Danielsx321/mind-master).

## Result

Lighthouse on mobile scores **100 / 100 / 100 / 100**, the whole page weighs **52 KB**, and layout shift is **0**.
